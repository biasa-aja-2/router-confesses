One line, under 200 characters, in which a home Wi-Fi router excuses
itself for dropping the connection at the climax of a movie.

> I watched the ending before you did, and honestly, you're better off not knowing.

## Why this line

The router is not apologising for a technical fault — it is confessing a
smug little secret: it has already seen the ending, and it cut the feed to
spare you. No buffering, no bandwidth, no firmware update; the joke is the
appliance with a grudge and a spoiler, and it lands in one breath.

## Run it

```sh
python3 main.py
```
